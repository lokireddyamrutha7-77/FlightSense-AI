# Models Directory

This folder holds trained serialized model artifacts generated by the `/ml` training pipeline.

## 📦 Expected Files

When training completes, the following `.joblib` binary artifacts should reside here:

1. `xgboost_flight_delay_latest.joblib` - Primary XGBoost binary classifier for delay probability estimation.
2. `feature_encoders_latest.joblib` - Categorical encoders (OneHotEncoder / TargetEncoder).
3. `feature_scaler_latest.joblib` - Numerical feature standardizers (StandardScaler / MinMaxScaler).
4. `shap_explainer_latest.joblib` - Serialized SHAP TreeExplainer for generating instant local feature attributions.

> **Note**: Heavy `.joblib` binaries are excluded from Git via `.gitignore`. Store production model versions in cloud artifact storage (e.g. AWS S3, GCP Cloud Storage, or MLflow Model Registry).
